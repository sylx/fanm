# シーズン 2026-11

最初の作り変え。`docs/seasons/` に前の記録は無い。読んだのは `var/season-input/plans.json` の
168作（2026-09-19〜2026-11-10）で、数えたのは直近60作（2026-10-26 以降）。60作の内訳は
型ごとに7〜8作、書き手は DeepSeek 28、Gemini 16、OpenAI 10、Claude 6。

## 数えたこと

**固まっていた段取り（直近60作、`composition` と `structure` から）**

- 縦スクロールシューティング：8作中8作が「上端16行はページ0の固定スコア帯（sprites:false）、
  下はページ1の256行リング平面、自機は多色、敵と弾は一色」。題材が変わっても画面は同じ。
  手引きの「点数の帯はページ0、地上はページ1」がほぼそのまま写っていた。
- 横スクロールアクション：8作中8作が上端16行の固定帯、7作がページ2・3の wide 平面を
  split で三〜四帯に分ける形。札（奥行き、足場）を替えても帯の数が変わるだけだった。
- RPG：8作中6作が16x16区画の地図、7作が「戦闘は別画面、上に敵、下に二重枠のコマンド」。
  手引きの「戦いは別の画面。上に敵、下に枠とコマンド」の文と同じ。
- アドベンチャー：8作中8作が「上が絵、下が文章の枠」（入れ替える作品も、上下の帯のまま）。
  手引きが「画面の作りは決まっている」と書いていた。
- ゲーム：7作中5作が上端16行の固定帯（シューティングとアクションの作法が移ってきた）。
  5作の段取りが「0〜10秒は自動デモ、10秒から操作」で始まる。
- 型をまたいで：60作中27作の段取りが「閃光」「白熱」「白く」で山場を作る。段取りか説明に
  「最初」（最初へ戻る、最初から）が出るのは41作、「反転」は21作。60作中57作がパレットを使い、
  27作の題材か構図に「夜」「闇」「暗」「黒」が出る。ページ間の写し（`gfx.blit`）を使った作品は0作。

**題と題材に写っていた札**

- 「色は補色の二系統だけで押し切る」：9回引かれ、題に「補色の塔」「二彩の跳梁」「二彩の坑道」
  「織機の朱藍」、題材に「補色の二系統」「青系と橙系」。いちばんひどく写っていた。
- 「三幕にする」（5回）→「三幕の石庭」。「折り返しがある」（3回）→「逆走の白路」、
  「往復逆走」「逆行」。「帯ごとに流れる向きが違う」→「逆流の回廊」。
  「白と黒に一色だけ差す」（4回）→「逆走の白路」「BLACK VEIN（白黒の配管網）」。
- 「同じ事が何度も起きるが、毎回少しずつ壊れていく」（6回）→ 題材の「崩壊」「亀裂」「裂け」。
  「崩」は直近60作の題と題材に8回。
- 「同じ場所を三度訪れ」→「三度目の窓」。「洞窟で、見えるのは主人公の周りだけ」（2回）→
  「灯痕洞」「洞穴の松明」。
- 題と題材によく出た語（60作）：道 9、海 8、崩 8、夜 7、星 7、石 7、灯 6、光 6、回廊 5。

**効いていなかった札**

- 「G4（256x212・16色）で作る」：10回引かれて最多だが、60作中40作がもともと G4。
  引いても何も変わらない。
- 「主役はすべて多色スプライト」：5回。実例がすでに多色なので、引かなくても25作が多色だった。
- 「後半で全部が加速する」（6回）と「一度きりの出来事が中ほどで起き…」（5回）：
  どちらも「白く光って逆転し、最初へ戻る」山場になり、引かなかった作品と見分けがつかない。
- 効いていた札：「動きは二重バッファの差し替えで作る」「画面の出来事と音を必ず結ぶ」
  「音は打楽器だけ」「線だけで描く」「戦いはなく、隠れて進む」。段取りかコードの形が変わっていた。

**一度も作られていないもの（168作）**：二人で遊ぶもの、曲が主役のもの、勝ち負けの無い
触るだけのもの、ページ間の写しで動かすもの、途中で画面モードを替えるもの。

## 入れ替えたもの

**休ませた型**（`retired` へ。ディレクトリは残した）

- `shooter`（縦スクロールシューティング）、`action`（横スクロールアクション）、`rpg`（RPG）。
  三つとも8作中6〜8作が同じ画面構成で、札を替えても帯の数と題材しか動かなかった。

**足した型**

- `versus`（対戦）：二人が同じ決まりで競う。無操作なら機械どうしが戦い、1P は `input` の 0、
  2P は 1。実例は、走った跡が壁になる陣取り（盤は配列で持ち、一升ごとに 4x4 を二つ描くだけ）。
- `music`（楽曲）：曲が主役で、絵は `compile` が返した `Song` の events をドライバと同じ数え方で
  追って作る。実例は、部分ごとに曲を掛け替え、鳴っている高さを右端の一列に打って
  スクロールで流すピアノロール。
- `toy`（おもちゃ）：勝ち負けの無い、触るだけのもの。無操作なら見えない手が触る。
  実例は、円の中に引いた線が八方に写る描画のおもちゃ（インクの色はパレットで回し、
  いっぱいになったら blitter の大きな円で片づける）。

三つとも `check:templates` を通った（versus 2700、music 2400、toy 2400 フレーム。描画待ち 0）。

**共通の札（`season.json` の `common`）**

- 軸「時間の運び」を丸ごと外した（三幕、壊れていく、加速、折り返し、一度きり。どれも題か
  山場の型に写っていた）。代わりに二軸を足した。
  - 「区切り方」：回数で区切る、場面の長さをそろえない、小節の頭で切り替える、動きを止める間。
  - 「周の終わり」：光らせずに一つずつ止める、音から抜く、終わりの画面を次の始まりにする、
    周ごとに配置を選び直す、端から片づける。27作の「閃光で最初へ戻る」を崩すため。
- 「色の使い方」→「色の決め方」に替え、全部差し替えた（補色、一色の濃淡、白黒に一色、
  時間で移す、場面でがらりと、を外した）。足したのは、乱数で色相を選ぶ、明るい地に暗い色で
  描く、明るさを三段だけ、二枚の絵を画素の値に重ねて setColor で片方だけ見せる、四色を場面で
  入れ替える。
- 「画面モード」：G4 を外し、G5（四色）と「途中で一度モードを替える」を足した。
- 「動きの出どころ」：split の帯と多色スプライトを外し、`gfx.blit` の写しと、blitter が描いていく
  途中を見せる札を足した。
- 「音の作り」：PSG 三声の追いかけを外し、場面ごとに曲を掛け替える、旋律を乱数で組み立てる、
  PSG をエンベロープで鳴らす、を足した。

**残した型の札**

- `ambient`：「埋まった画面から失われていく」（3回、全部消失で終わる）と「奥へ進み続ける」
  「下から見上げる」を外し、軸「動くものの数」を足した。
- `game`：「点数と残機を画面の上に出す」「横に流れ続ける」「画面が回る・反転する」「避ける」
  「撃ち落とす」「追いかける」を外し、押す、揃えて消す、探り当てる、一画面ずつ渡る、
  点を音で知らせる、を足した。
- `poem`：「絵が言葉をそのまま映す」「絵が言葉を少しずつ消していく」「同じ一行を繰り返し」
  「字に分解して散らす」「中央に寄せる」「端から端へ流す」を外し、一語ずつ置く、書いては消す、
  一筆ずつ描き足す、絵を描かない、行の頭を揃えない、字を拡げる、を足した。
- `adventure`：「上が絵、下が文章の枠」「同じ場所を三度訪れ」「前の場面の絵が残っていく」
  「同じ構図を使い回す」「一枚の絵を描き足して完成」「一字ずつ出す」を外し、右に縦長の文章欄、
  選んだ答えで絵の一部が変わる、移る途中の絵でつなぐ、拡げた点の絵、描き上げる途中を見せる、
  話し手ごとの位置、吹き出し、を足した。
- `tiles`：「別のバンクで上と下で違う世界」「少しずつ別の文字に置き換わる（崩れる）」
  「buffer.shift」「二重バッファ」を外し、縦スクロール、スプライトが主役で升目は舞台、
  隣を見て次の文字を決める升目、数や記号の表、を足した。

**手引きの書き直し**

- `adventure/form.md`：「画面の作りは決まっている。上に一枚絵、下に…この型は、その枠が
  あることが本体」を消し、割り方を何通りか挙げた。
- `game/form.md`：「自動デモ」と「操作の解放」は段取りではないと書き、点数の置き場所は
  上の帯と決まっていないと書いた。
- `ambient/form.md`：パレットの例から「稲光で一瞬だけ白くする」を外し、終わりに白く光らせて
  戻す形が多いこと、暗い地が多いことを書いた。写しと blitter の遅さを動きの出どころに足した。
- `poem/form.md`：「暗い地に一つの光景（雨、水面、地平、窓）」を外した。「無音でもよい」は
  `prompts/rules.md`（無音にしない）とぶつかっていたので直した。
- 実例（`work.ts`）は、残した型のものには触っていない。

**シーズンの名前**：今月は 2026-11 で、`season` はもとから `2026-11` だった。そのまま。

## ねらい

- 画面の作りが型ごとに一つへ収まっていた三つを休ませ、人の関わり方が違う三つ（二人で競う、
  聞く、触る）を入れる。来月は「上端16行の固定帯＋スクロール平面」の作品が目に見えて減ること。
- 山場の作り方を散らす。「白く光って最初へ戻る」に代わって、止まって終わる、音から消える、
  次の周が違う並びで始まる作品が出てくること。
- 夜と暗い地と「灯」から離れる。明るい地、昼、乱数の色相の作品が出てくること。
- `gfx.blit` の写しと、blitter が描いていく途中を見せる作品が、初めて出てくること。

## 次の係へ

- 新しい型は直近の作品が0なので、入れた直後は `pickForm` が三つを続けて当てる（24作の窓で
  ほかの型と並ぶまで）。九作ほどは versus / music / toy が並ぶはず。
- `versus`：2P の側は検査で一度も押されない（下の提案）。2P の入力で壊れていないかは、
  ギャラリーで実際に WASD を押して確かめてほしい。機械どうしの勝負が毎回同じ形になって
  いないかも見る。
- `music`：絵が楽譜から作られているか（events を追っているか）、それとも別の時刻表を手で書いて
  いるかを確かめる。手で書いた作品が多ければ、手引きの書き方を強める。
- `toy`：「見えない手」が単調でないか。「見えない手は出てこない」の札は、操作しないと何も
  起きない作品を生むおそれがあるので、引かれた作品を見る。
- 怪しい札：「一つの画面に二枚の絵を持つ（色×4＋色）」は手間が大きく、G7 と一緒に引かれると
  成り立たない。「途中で一度 screen.setMode」は描き直しが重い。どちらも落ちた作品が多ければ外す。
- `adventure` は札と手引きだけ替えて、実例（`work.ts`）は上が絵・下が文章のまま。来月も
  上下の割りが続くなら、実例の `VIEW` と `WINDOW` の置き方を替えるか、休ませる。
- 今回外した語のうち、「回廊」「灯」「反転」「崩」が来月も題に残るかを数える。

## 人への提案

- **検査で 2P も押す。** `check/check.ts` の `inputsFor` は player 0 のボタンしか押さない。
  `versus` の作品は 2P 側の入力の道を一度も通らないまま採用される。押す入力の半分を
  player 1 に振るか、`controls` に「2P」とある作品だけ両方を押すとよい（`ScenarioInput` に
  player を足す必要がある）。
- **使い古した語を段取りからも数える。** `plan/planner.ts` の `wornWords` は題と題材だけを
  数える。今回いちばん繰り返されていたのは段取りの「閃光」「白熱」「反転」「最初へ戻る」で、
  題には出ないので名指しされない。`structure` の語も数えるか、段取りの型（山場と締め方）を
  別に数えて渡すとよい。
- **シーズンの名前が最初のシーズンと同じになる。** 最初の顔ぶれも `2026-11` と名付けられて
  いたため、今回の入れ替えも同じ名前で企画に残る（いま名前の付いた企画は2作だけなので
  実害は小さい）。月の途中で作り変えることもあるなら、`season.ts` の形の決まりを
  `2026-11b` のような枝番まで許すとよい。
- **自動デモを段取りに書かせない。** `prompts/rules.md` の「操作できる作品」の節が、ゲームの
  企画の段取りを「0〜10秒は自動デモ」で始めさせている。`prompts/plan.md` の `structure` の
  説明に「人が触るかどうかは段取りに書かない」と一言足すとよい。

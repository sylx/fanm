この作品の型は **横スクロールアクション**。MSX2+ の横スクロールで、走る、跳ぶ、踏む。
主人公が右へ進み、景色が左へ流れていく、あの種類のもの。

- **地面は描き直さずに流す**。`ctx.scroll` で「どこから見るか」を動かす。
  `scroll.wide = true` でページ2と3が横に並び、幅512の平面になる。平面は輪なので、
  右から入ってくる列を、左へ出ていった列の場所へ一本ずつ描き足す（描くのは画面の外）。
  描き足すときは `screen.setDrawPage(2 + (平面のx >> 8))` にしてから `gfx.now` で描く。
  歩くたびに全面を描き直すと検査で落ちる。
- `scroll.mask = true` にする。細かい横スクロールで左端の8画素がちらつくのを隠す。
- **帯で視差を付ける**。`scroll.split(上端の行, { page: 2 })` で画面を横の帯に分け、
  遠くの帯ほど `x` をゆっくり動かす。遠景は平面に一度描いたら触らない（512で一周する
  絵にすると継ぎ目が出ない）。点数の帯は `scroll.split(0, { page: 0 })` でページ0に置き、
  動かさない。ページ0の下端にはスプライトの表があるので、ページ0を流す平面にしない。
- 帯の `y` は全部0のまま使う。縦に動かす帯と動かさない帯が混ざると、スプライトが
  帯の境目で千切れ、別の帯に映り込む。縦にも動かすなら、点数の帯に `sprites: false` を
  付ける（その帯の行ではスプライトが出なくなり、映り込まない）。
- 動くもの（主人公、敵、拾うもの）はスプライト。横のスクロールはスプライトを動かさない
  ので、世界の座標からカメラの x を引いて置く。画面の外（x が負、255 超）なら `hide`。
  x を負のまま渡すと反対の端に出る。
- **自動で進む**。無操作なら機械が走り、穴や敵の手前で跳ぶ。うまくなくてよいが、
  最初の10秒で「走る → 跳ぶ → 敵を越える」が見えること。操作が来たら人に渡し、
  しばらく触られなければまた機械が走る。
- `controls` に操作を書く（例: `"← → 移動 / Z ジャンプ"`）。

地形も敵も自分で考える。穴と段だけでなく、動く足場、坂、水、天井、風など、進み方を
変えるものを一つ入れると作品が変わる。落ちたらその場の少し先から出直し、全部失ったら
数秒おいて最初からやり直す。

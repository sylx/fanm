この作品の型は **楽曲**。曲が主役で、絵は曲に従う。MSX の PSG（三声）と FM 音源（OPLL）と
打楽器で一曲を書き、画面はその曲を見せるためにある。

- 曲を先に書く。30〜60 秒で、始まりと終わりのある形にする（部分を並べる、声を足していく、
  調を変える）。同じ四小節を回し続けるだけの曲にしない。
- **絵は楽譜から作る。** `compile` が返す `Song` の `tracks[].events`（`note` の `semitone` と
  `frames`、`rest`、`drum` の `mask`）を、`update` で一フレームずつ数えて追う。鳴った瞬間、
  今の高さ、残りの長さが分かる。時刻表を別に手で書かない。曲を直せば絵もついてくる。
  数え方はドライバと同じ: 長さ 0 の出来事（音量、音色）はその場で読み進め、
  `note` は `frames` だけ続き、鳴っているのはそのうち `frames * gate / 8` まで。
- 曲を部分ごとに `compile` しておき、`bgm.play(song, { loop: false })` で掛け、追っている
  全部の声が終わったら次を掛けてもよい。一曲を `loop: true` で回すなら、追う側も
  `track.frames` で巻き戻す。
- 絵の作り方は幅がある。音の高さを位置にする、声ごとに画面の一部を受け持つ、打楽器で
  パレットを進める、鳴るたびに一筆ずつ描き足して終わりに一枚の絵にする、人形が楽器を
  弾く、歌詞を出す。どれでも、毎フレームの描画は「今鳴った音のぶん」だけにする。
  画面全体の変化はパレットとスクロール、動くものはスプライト。
- 打楽器は `rhythmVoice()`。c がバスドラム、d がスネア、e がタム、f がシンバル、
  g がハイハット。同時に鳴らすものは `{cg}`。打楽器を使うと FM の `opllVoice(6)`〜`(8)` は使えない（使えるのは 0〜5）。
- `bgm.effect` は曲の声を一つ借りる。この型では効果音より曲を優先し、借りるなら短く。

操作はしない。`controls` は空文字。`durationFrames` は曲を一通り聞ける長さ。
文字を出すなら、ASCII は `gfx.text`、日本語は `ctx.text`（`@fanm/work` の `DOT_STYLE`）。
既にある曲の旋律を写さない。旋律は自分で書く。
